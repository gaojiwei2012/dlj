# 逗留记 V1 交付状态

更新：2026-09-23。本仓库是真实应用源码；此前的 Sites 地址仅是界面原型，账号与记录互不相通。

## 已实现

- Vue 3、Node.js、SQLite、Docker Compose、Caddy HTTPS 和每日数据库备份。
- 邀请码注册、两次密码校验、账号密码登录、个人修改姓名和密码、管理员生成与停用邀请码及重置用户密码。
- 北京时间签到和签退、按日期补录签退、修改或删除记录；入澳和离澳当天均计入，同日重叠只算一次。
- 管理员设置学年、目标天数、无效日期和带时间地点的课程；学年修改会检查重叠和既有配置范围。
- 课程 tab 只读，独立入口按每次集中课选择日期；未来日期可预选，到当天才进入已完成统计。
- 日历真实切换月份，全部逗留记录按最近日期排序；普通用户排行仅前三名，管理员可看全部。
- 私密出行计划只需两个日期；公开后补充城市、交通方式和自驾座位，寻搭子仅展示未过期的公开计划。
- 数据库备份与停机恢复演练、生产初始化配置检查。

## 仍需在真实服务器验证

1. 域名解析、腾讯云端口放行、Docker Compose 启动和 Caddy 自动签发证书。
2. 手机端登录与安装 PWA；签到、签退、课程、无效日期、排行的人工验收。
3. 实际服务器上查看每日备份，并停机恢复一次。
4. 邀请 5 至 10 位用户试运行一周，核对计算结果与页面反馈。

具体命令与顺序见 [deployment-checklist.md](deployment-checklist.md)。测试通过仅证明本地接口和构建正常，不能替代服务器及真实用户验收。
