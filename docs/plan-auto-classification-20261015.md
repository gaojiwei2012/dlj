# R002 出行计划自动课程识别（2026-10-15）

## 行为

1. 新建、编辑计划时不提供手工「自行安排／课程安排」选择器。
2. 计划日期选择器从已有只读 `/api/travel-plans/date-check` 获取 `isCourseDay`，与逗留日历统一显示右上角紫色「课」。原黄色澳门公共假期标识继续显示；两个标记同时存在时不遮挡。
3. 选完日期后在表单预览自动分段；「我的出行计划」通过 `GET /api/travel-plans` 的 `segments` 动态展示。每一段含 `type`、`startDate`、`endDate`；连续相同类型合并为一个区间。
4. `COURSE` 依据管理员已发布且状态 ACTIVE 的 `course_sessions`/`course_dates`；未安排课程的日期为 `SELF`。课程可能和公共假期同时存在，此处标签仅表示是否排有课程，**不代表该日被认定为有效逗留**；预测仍沿用无效日与假期优先规则。
5. 混合分类只影响 UI 展示。出行记录、联系人、公开信息、座位预约、计划预测仍以原计划单条 `id` 和完整日期范围计算，不额外创建计划、不拆分或重复累计日期。
6. 原数据库列 `plan_type` 和旧请求参数保留兼容，不新增迁移；历史手工标签不再作为界面分类依据。管理员发布、调整、停用课程后，下次读取计划时自动更新分段。

## 验证

- `test/auto-plan-segments.test.mjs`：纯自行、纯课程、混合跨年、日期去重及界面入口检查。
- `test/auto-plan-api.test.mjs`：GET 分段与课程的新增、调整、停用动态联动，并确认原计划 ID 与条数不变。
- `npm test`：执行全部现有测试。
- 部署环境需运行 `npm ci && npm run build` 并实际点击验收日期选择器、计划分段与原有预约操作。
