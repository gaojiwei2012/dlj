|---|---|---|

## 三项比值展示补充验收

- [ ] 一名学生完全符合 1 天、部分符合 2 天、学年目标 90 天：列表和详情显示 1/90、2/90、3/90；没有计划预测／净差异列。
- [ ] 顶部只有这一名学生时，三个汇总比值为 1/90、2/90、3/90。
- [ ] 两名学生目标均为 90 时，顶部汇总的分母为 180；搜索只改变列表，不改变全体汇总。
- [ ] 切换目标天数不同的学年，分母随 API 的 `targetDays` 自动变化，无硬编码 90。
- [ ] 375px、390px 和 430px 宽度下，三项比值及查看详情按钮均无遮挡。
