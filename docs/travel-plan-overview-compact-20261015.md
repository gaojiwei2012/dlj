# 2026-10-15 计划出行页面精简

## 页面变化

- “本学年计划预测”卡片精简为“出行计划统计”，只保留三个数据块：已计划、本年计划、本月计划。
- “已计划”：当前所选学年内，所有有效出行计划覆盖的自然日，重叠日期只计一次。**包含已经过去和未来计划**。
- “本年计划”：上述日期中属于北京时间**当前公历年份**的天数。
- “本月计划”：上述日期中属于北京时间**当前公历月份**的天数。
- 删除第四个“去重计划天数”指标（其含义已合并到“已计划”）。
- 页面不再呈现“截至当前可结算日期”、实际对照、差异说明和逐日对照表。
- 其他部分（计划新增、自动识别课程日、出行计划列表、修改与删除、签到记录和后台管理）保留。

## 兼容性说明

- 为避免影响已有接口或“我的出行计划”单条预测，后端仍保留 forecast 的原有预测字段和 comparison/dailyResults 数据，新增 overview 对象提供三个计数字段，forecast 结构保持不变。
- 使用 GET /api/travel-plans/prediction 或 dashboard 时按服务器当前北京时间计算本年、本月；无需数据库迁移。
- 测试覆盖日期去重、学年边界、软删除过滤和跨年时区切换。
