# R002 计划预测与实际偏差验收清单

**状态**：开发代码已集成，自动测试通过，以下浏览器操作尚待在 Linux 3200 测试站执行。默认学年为 2026—2027；测试前请确认所用日期在该学年内。仅使用测试账号和测试库。

| ID | 操作 | 期望 | 核心自动测试 |
|---|---|---|---|
| P01 | 学生新增私密计划 | 卡片出现，参与预测，未进入公开寻搭子 | API |
| P02 | 新增公开计划 | 参与自己预测，仍出现在符合公开规则的寻搭子 | API/人工 |
| P03 | 计划覆盖周五至周一 | 首尾均计，普通周末预测部分符合 | 纯计算 |
| P04 | 新增与现有计划重叠两天的计划 | 汇总按自然日去重，单计划分项不强行相加 | 纯计算/API |
| P05 | 老师设置有效周末，学生刷新 | 该计划日预测由部分符合变完全符合 | 纯计算/人工 |
| P06 | 老师把同日设置为公共假期 | 计划预测变不符合；节假日覆盖有效周末 | 纯计算/API |
| P07 | 老师设置课程周末 | 同日模拟满4小时可完全符合，除非强制排除 | R001复用/人工 |
| P08 | 建立未来计划，无实际签到 | 全量预测增加，未兑现与截至今日应完成不提前增加 | 纯计算/API |
| P09 | 历史计划工作日，无真实签到 | 计划 FULL，实际 NO_STAY，未兑现 +1 | 纯计算/API |
| P10 | 无计划日补录工作日09:00–13:00 | 额外完成 +1 | 纯计算/API |
| P11 | 一天未兑现、另一天额外完成 | 净差异可以为0，但两项偏差和逐日原因仍出现 | 纯计算/API |
| P12 | 历史计划覆盖公共假期，但当天没去 | 计划 NON_COMPLIANT，实际 NO_STAY，不能把没去算实际不符合 | 纯计算 |
| P13 | 今天保持 OPEN 签到 | 当天进行中、不提前算未兑现 | 纯计算/人工 |
| P14 | 今天已经签退且无 OPEN | 使用已结束的真实时长更新对比；如继续签到再次重算 | 纯计算/人工 |
| P15 | 更换学年 | 计划/预测、Dashboard 同步切换，跨年计划只在交集范围内贡献 | 纯计算/API/人工 |
| P16 | 点击「查看全部历史计划」 | 可看历史计划，默认只展示当前学年相关计划 | API/人工 |
| P17 | 点击「查看全部历史」逗留记录 | 默认只看当前学年，选择全部可看原记录；跨年记录两学年都可筛到 | API/人工 |
| P18 | 修改或删除旧计划 | 重新以当前有效计划计算；页面提示历史计划快照未保留 | API/人工 |
| P19 | 普通学生试图查询另一用户预测 | 接口没有指定他人用户的能力；只能获得自己的数据 | API |
| P20 | 老师/学生宽屏和手机窄屏检查 | 原 R001 日期管理布局修复保持；R002 卡片、明细无明显溢出 | 人工 |
